Project Summary
StockSense is an advanced AI-driven stock analysis platform that provides investors with comprehensive real-time insights for informed decision-making. It integrates fundamental and technical evaluations, sentiment analysis, and peer comparisons to deliver precise buy, hold, or sell recommendations. The platform features extensive market data, including stocks, mutual funds, IPOs, and indices, ensuring users receive timely updates and in-depth analysis.

Project Module Description
Frontend: Developed with React and Tailwind CSS, featuring a responsive UI with interactive charts, user authentication, and real-time data visualization.
Backend: Built using Node.js and Express, it serves as the API for user authentication and data processing.
Professional Stock Analysis: Comprehensive stock analysis module that includes fundamental, technical, sentiment, and peer insights, now integrated with the Alpha Vantage API.
Database: MongoDB is utilized for storing stock-related data and user information.
Real-Time Market Data Service: Delivers live updates on various financial instruments using multiple APIs.

Technology Stack
Frontend: React, Tailwind CSS, Recharts
Backend: Node.js, Express
Database: MongoDB
Authentication: Passport.js, Google OAuth, Mock Authentication
Real-Time Data: Alpha Vantage API and other APIs for live stock data
Analytics Workers: Python (future enhancement)
Usage
Installation
Clone the repository:

git clone <repository-url>
cd shadcn-ui
Frontend Setup:

pnpm install
pnpm run dev
Backend Setup:

cd backend
npm install
npm start
Authentication
Users can sign up or log in using email/password or Google authentication. A fallback authentication system allows users to log in or create accounts even if the backend is down.
